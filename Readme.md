# S-Music

## Descripción

A website about discovering new music and breaking out of the algorithm, made using only HTML and CSS. It features a responsive header and footer, three full-screen sections, and a gallery of 12 artists with their descriptions. The icons are from Google Material Symbols.

## Responsive Design

- **Desktop-first** layout built with Flexbox.
- Desktop styles are the default.
- Tablet styles apply at widths up to `991px`.
- Mobile styles apply at widths up to `767px`.

## Semantic HTML

The page uses semantic elements: `header`, `nav`, `main`, `section`, `article`, `aside`, `figure`, and `footer`.
